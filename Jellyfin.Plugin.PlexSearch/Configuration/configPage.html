Plex Search

Adds an On Plex section to Jellyfin search, using a Plex server you own or that is shared with you.

1. Plex account

Checking…

A Plex sign-in page has opened in a new tab. Approve it there, then come back. This page updates by itself. If nothing opened, open the Plex sign-in page.

2. Plex server

3. Libraries and options

Tick the libraries to search. Leave all unticked to search every movie and TV library.

4. Show results in search

Nothing else to install: Plex Search adds itself to the Jellyfin web app. After installing or updating, refresh the Jellyfin web page (Ctrl+F5) and restart the Android app.

Not showing up? Use JavaScript Injector instead

If a reverse proxy or app caches the page, install the JavaScript Injector plugin, add a new script, and paste this in. It's safe alongside the automatic version.
